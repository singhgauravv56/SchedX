================================================================================
                      🔍 WHAT GETS CHECKED
================================================================================

Before scheduling ANY time slot, the system verifies:

1. ✓ Room type matches requirement (Classroom vs Lab)
2. ✓ Room capacity ≥ number of students
3. ✓ Teacher not already busy at that time
4. ✓ Class not already occupied at that time
5. ✓ Room not already booked at that time
6. ✓ Time is within working hours
7. ✓ Day is within working days
8. ✓ Teacher is qualified for the course
9. ✓ All required inputs provided
10. ✓ Database constraints enforced
11. ✓ No conflicts in MySQL (UNIQUE keys)

If ANY condition fails → Clear error message → No fake timetable created

================================================================================
                        🔗 API ENDPOINTS
================================================================================

Base URL: http://localhost:3000/api

DEPARTMENTS:
   POST   /api/departments              Create department
   GET    /api/departments              List departments

TEACHERS:
   POST   /api/teachers                 Create teacher
   GET    /api/teachers                 List teachers
   DELETE /api/teachers/:id             Delete teacher

COURSES:
   POST   /api/courses                  Create course
   GET    /api/courses                  List courses
   DELETE /api/courses/:id              Delete course

CLASSES:
   POST   /api/classes                  Create class
   GET    /api/classes                  List classes
   DELETE /api/classes/:id              Delete class

ROOMS:
   POST   /api/rooms                    Create room
   GET    /api/rooms                    List rooms
   DELETE /api/rooms/:id                Delete room

TIMETABLE:
   POST   /api/generate-timetable       Generate from form data
   GET    /api/timetable                Get saved timetable
   DELETE /api/timetable                Clear timetable

SYSTEM:
   GET    /api/health                   Check database status

================================================================================
                      🐛 QUICK TROUBLESHOOT
================================================================================

Problem: "Cannot GET /"
→ Solution: Make sure to run `npm start`, don't open HTML directly

Problem: "MySQL is not reachable"
→ Solution: Start MySQL service
→ Check .env file for correct credentials
→ Ensure database user has proper permissions

Problem: "Port 3000 already in use"
→ Solution: Edit .env and change PORT to 3001 (or other available port)
→ Or: Kill process using port 3000

Problem: Form shows "Please provide all required information"
→ Solution: Fill ALL fields marked with * (asterisk)

Problem: "No suitable room available"
→ Solution: This shouldn't happen - system creates room if needed
→ Check student count and room type selection

Problem: Timetable not persisting after refresh
→ Solution: Check MySQL is running
→ Verify database connection in .env
→ Check browser console for errors (F12)
